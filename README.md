# Personal Portfolio Website

Welcome to my personal portfolio website!

This project is a simple and elegant portfolio website created using **HTML and CSS**. It showcases my profile, skills, interests, projects, and contact information in a clean and user-friendly design.

## Features

- Personal introduction
- About Me section
- Skills and interests
- Projects showcase
- Contact section
- LinkedIn profile
- Clean and simple UI

## Technologies Used

- HTML5
- CSS3
- Google Fonts

## Purpose

I created this project to practice my HTML and CSS skills and to build a simple personal portfolio that represents me as a Web Developer.
